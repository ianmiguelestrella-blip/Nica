# Monthsary Website for Nica Sarmiento ♡

## Files
- `index.html` — page content and love letter
- `style.css` — design and responsive layout
- `script.js` — surprise button interaction

## Preview
Open the folder in VS Code and run `index.html` with Live Server, or open it directly in your browser.

## Publish in your existing GitHub repository
1. Copy these files into the root of your existing repository.
2. Edit the letter and memory-card text in `index.html`.
3. Run `git add .`, `git commit -m "Add monthsary website for Nica"`, then `git push`.
4. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select your branch (often `main`) and `/(root)`, then Save.

This is a static website. The surprise button works in the browser; it does not send messages externally. Add photos to the repository and update the memory cards in `index.html` if you want to include pictures.
